# Reclaim Threads

A responsive clothes reselling website foundation built with HTML, CSS, and JavaScript.

## What this site includes

- Landing hero section with stylish product highlight cards
- Marketplace grid for product listings
- Listing form to upload photos and create new sellable items
- Local storage persistence for product listings
- Responsive layout for desktop and mobile

## How to use

1. Open `index.html` in your browser.
2. Scroll to the **Sell your style** section.
3. Add a title, description, price, category, and photo.
4. Submit to add the listing to the marketplace.
